# The Herd Co.

Sites, apps, and AI agents for teams that run lean. Static site served by GitHub Pages from `main`.

- `index.html` — the whole public site
- `portfolio.html` — portfolio (hidden / unlinked for now)
- `admin/` — password-locked operations dashboard (pipeline, contracts, site architecture). No data lives in this repo.
- `apps-script/ops/` — the private Google Sheet backend for `admin/` + setup steps
- `assets/ops-config.js` — the ops backend URL (used by `admin/` and the consult form)
- `assets/` — logo set (full, horizontal, icon, white), favicons
